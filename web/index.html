DIRECT FROM THE SOURCE

How this list stays current

A GitHub Actions job checks NRC nightly at 08:17 UTC (3:17 a.m. Central daylight time; 2:17 a.m. Central standard time). It validates and saves the findings, then publishes this site. GitHub may delay scheduled runs.

Each visit loads the latest published snapshot. Reloading checks for a newer snapshot; it does not contact NRC or trigger the nightly job. Failed updates leave the previous successful site available, and a warning appears when the retrieval is over 48 hours old.

Descriptions, classifications and report links come from NRC. Event dates can represent the end of an inspection period. Green is a finding classification, not an overall plant safety rating. A missing record does not establish that there are no safety issues.
